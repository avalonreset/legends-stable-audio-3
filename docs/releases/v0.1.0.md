# Legends Stable Audio 3 v0.1.0 - Historical Private Pre-Public Release

Initial preview release of the Stable Audio 3 agentic operator.

## Highlights

- `legends-sa3` CLI with doctor, model download, planning, generation, and mixing commands.
- VRAM-aware planning for 8 GB, 12 GB, 16 GB, 20 GB, and 24 GB class GPUs.
- Validated 24 GB class formula: 98 tracks, 380 seconds each, 12 second crossfades, about 10:01:16.
- Resumable MP3 track generation.
- Streaming crossfade mixer for long MP3 masters.
- Lo-fi study music preset.
- Codex, Claude, and Gemini compatible agent entrypoints.
- Documentation for model access, VRAM tuning, troubleshooting, and commercial-use caveats.

## Safety boundary

This release does not include Stable Audio model weights. Users must accept the
gated model terms and download model files into their own local environment.

## Validation

- Unit tests passed.
- Package compile check passed.
- 10-hour planning smoke test returned 98 tracks and 36076 seconds.
- CUDA doctor check detected RTX 4090 24 GB class GPU and recommended 380 second segments.
- Real 12-second generation smoke test produced a verified MP3.
