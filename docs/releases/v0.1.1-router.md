# Legends Stable Audio 3 v0.1.1

Hosted Large generation could submit successfully and then fail to download
with HTTP 400 because the result request sent `Accept: audio/wav` or
`audio/mpeg`. The service requires `Accept: audio/*`.

This patch corrects result negotiation for both supported formats. The
generation request still selects WAV or MP3, and downloaded media types and
file signatures are still validated.

If an earlier run left a pending receipt, recover that generation with
`legends-sa3 large result --generation-id <saved-id> --output recovered.wav
--output-format wav`. Keep the pending receipt and use a separate recovery
receipt path. Do not resubmit a paid job merely because its download failed.

The fix was verified by recovering an existing hosted Large WAV and completing
fresh hosted Large generations. MP3 negotiation has regression coverage;
this release does not claim a separate live MP3 generation.

The development dependency lock also updates urllib3 from 2.7.0 to 2.8.0,
addressing the three advisories reported by the release dependency audit.

Install or update through the single `cto-legends` router. No additional
module skill registration or local model download is needed for hosted Large.
