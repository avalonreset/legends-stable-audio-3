# v0.3.0 - Historical Private Pre-Public Release

This preview release shifts Legends Stable Audio 3 from preset-first operation
to prompt-first operation. Presets still exist, but they are now recipes: optional
scaffolds for repeatable batches, not a required catalog of genres.

## Added

- `--style` / `--prompt` for free-form Stable Audio style requests.
- `legends-sa3 prompt` for previewing expanded prompts before long runs.
- `legends-sa3 analyze` for inspecting source-track cue quality before mixing.
- `--negative-prompt`, `--allow-vocals`, and `--bpm` generation controls.
- `docs/prompting-guide.md`, based on Stability AI's current Stable Audio 3
  prompting and inference guidance.

## Changed

- `--genre` remains available, but it is now a compatibility alias for
  `--recipe`.
- Documentation now teaches users to describe the target audio directly:
  genre/style, instruments, mood or energy, BPM, and production character.
- Agent instructions now route through prompt preview, generation, analysis, and
  active-cue mixing.

## Why it matters

Users should be able to ask for "trance hip hop jazz" without waiting for a
hard-coded preset. The operator now expands a free-form request into a more
Stable-Audio-friendly prompt while preserving the user's actual style direction.

The analyzer also makes the quiet-head and quiet-tail problem visible before
mixing. This is the practical guardrail learned from the one-hour trip-hop trance
test run.

This release still does not include Stable Audio model weights, generated music,
or any license promise for user-generated outputs.
