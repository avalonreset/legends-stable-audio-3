# legends-stable-audio-3 v0.1.2

Full songs should have room to develop. Hosted Large now sends 380 seconds by
default. Under current flat-rate pricing, a shorter generation does not save
credits. Explicit durations remain available for short cues, SFX and documented
quality-driven changes.

The production workflow separates individual songs from approximate set
runtime. `production-plan --minutes 20` plans four full songs without demanding
a 20-minute export. `arrange` renders source-specific cue sheets, with separate
overlaps and optional independent fade lengths per pair. Every source trim and
discovery promotion requires a reason. Float WAV rendering retains headroom
for mastering instead of clipping overlap peaks.

The bundled instructions remove the former short dense-D&B preference. They
require calibration at production length, reuse of good recordings, and an
honest distinction between signal checks and listening review. The upstream
report's long-duration prompt-drift finding remains a documented risk to test.

Validation includes automated behavior tests and a private live production
using four fresh 380-second hosted recordings. Generated music and private
production data are not distributed in this repository. Source-specific
musical decisions remain operator responsibilities; this release does not
claim automated listening, phrase detection or beat matching.

The current one-skill `cto-legends` architecture is preserved.
