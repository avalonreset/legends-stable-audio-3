# v0.4.1 - Public Onboarding Polish

Legends Stable Audio 3 v0.4.1 is a focused documentation, packaging-metadata,
and repository-configuration follow-up to the first public release. It does not
change generation behavior or the paid-action contract.

## Highlights

- Leads with the product's agent-first value: route the right Stable Audio 3
  surface, shape stronger prompts, run seed tournaments, preserve recovery data,
  and assemble long mixes without depending on a private vault.
- Adds a copyable GitHub Release wheel installation path and makes the canonical
  skill installation flow visible near the top of the README.
- Separates local Medium, hosted Large, web studio, DAW plugin, and downstream
  mixing in the public feature map.
- Links CTO Legends from GitHub-facing and Python package metadata.
- Removes stale pre-publication statements from the README and security policy.
- Updates Hugging Face login guidance to `hf auth login` and documents the
  `STABILITY_API_KEY` boundary without storing a secret.
- Expands the continuous test matrix to Windows, Ubuntu, and macOS on Python
  3.10, 3.12, and 3.14.
- Corrects the canonical skill's surface count and regenerates every mirror.
- Prevents future releases from passing while stale private/unreleased language
  remains in active public files.

## Compatibility and safety

The Apache-2.0 source boundary, separate model/dependency terms, explicit paid
confirmation, no-resubmit recovery, output overwrite protection, secret-free
receipts, model-weight exclusions, and clean wheel/source install checks remain
unchanged.
