# v0.4.0 - First Public Release

Legends Stable Audio 3 v0.4.0 is the intended first public release candidate.
It turns the private-preview CLI into a coherent Apache-2.0 source distribution
for local Stable Audio 3 Medium operations, careful hosted-surface planning,
native adapter workflows, audio analysis, and cue-aware long-form mixing.

No tag, package publication, public repository, or GitHub release is created by
this preparation work.

## Highlights

- One canonical agent skill now serves Codex, Grok, Claude, and Gemini through
  generated repository mirrors and small platform adapters.
- The wheel includes the same canonical skill bundle. After `pip install`, use
  `legends-sa3 skill validate` and an explicit
  `legends-sa3 skill install --target <skills-directory>`; global locations are
  never guessed and existing skill directories are never overwritten.
- Prompting defaults now reflect the recovered Stable Audio 3 guidance: concise
  metadata-plus-prose prompts, 8 Ping-Pong steps, CFG 1.0, explicit positive
  instrumental tags, seed tournaments, and clear Medium/Large/web boundaries.
- Guarded `legends-sa3 large plan/generate` commands cover the current Stable
  Audio 3 Large text-to-audio, audio-to-audio, and inpaint REST lifecycle. Paid
  execution requires a live-confirmed credit value, `--confirm-paid`, and an
  API key loaded only from `STABILITY_API_KEY`; results are polled, downloaded,
  hashed, and accompanied by a secret-free receipt. Pending receipts preserve
  generation IDs for no-resubmit recovery, existing files are protected by
  default, uploads are duration-checked, and responses are validated as audio.
- Native Stable Audio 3 LoRA/DoRA checkpoints can be loaded explicitly, while
  adapter weights, datasets, model weights, and generated media remain outside
  source and package artifacts.
- The optional Underfit LoRA Studio bridge is pinned to reviewed commit
  `8a96800a58c0e8b82327fc04ac31c473ed900b73` and verifies origin, commit,
  required files, and MIT license hash before any downloaded script runs.
- Active-cue analysis and streaming crossfades preserve reliable long renders
  without forcing every use case into background or instrumental music.

## Release engineering

- Windows and Ubuntu CI run unit tests, the 10-hour planning invariant, skill
  sync validation, Git-less source-export tests, build-content inspection, and
  clean wheel/sdist installs.
- Security jobs use pinned action commits, least-privilege permissions, Gitleaks,
  `pip-audit`, forbidden-artifact checks, and CycloneDX/license reports.
- Frozen Ruff checks cover Python source, tests, and release tooling.
- Package metadata uses the PEP 639 `Apache-2.0` expression and includes LICENSE,
  NOTICE, third-party notices, and the installable skill bundle.
- Runtime constraints and dependency-policy documentation define the supported
  reproducibility boundary without pretending CUDA/PyTorch wheels are universal.
- Hosted Large polling retries transient result-fetch failures within a bounded
  budget, rejects credential-bearing redirects, validates runtime numeric types,
  and never automatically retries the paid submission.
- The Medium downloader now stages the required T5Gemma conditioning bundle and
  validates that the local model directory is complete before inference.
- The source archive preserves repository-level Codex, Grok, Claude, and Gemini
  adapters; clean wheel and sdist installs preserve the same portable skill
  knowledge library.

## Upgrade notes

- Public product wording is now “Legends Stable Audio 3”; the repository slug is
  `legends-stable-audio-3`.
- Underfit `--repo-url` and `--ref` overrides are removed from the public CLI.
  Installation is intentionally tied to the reviewed revision.
- Existing manually installed agent skills are not replaced automatically.
  Remove or move an old target explicitly before installing the v0.4.0 bundle.
- This release does not bundle or download a model during installation.
