# Support

Use GitHub Issues for reproducible bugs and focused feature requests:

`https://github.com/avalonreset/legends-stable-audio-3/issues`

Before filing, run `legends-sa3 doctor`, remove tokens and private paths, and
include the command, package version, operating system, Python version, GPU/VRAM,
and relevant error output. Do not upload model weights, adapters, datasets, or
licensed/generated media.

Questions about Stability AI model access, commercial eligibility, hosted
service billing, or model behavior depend on third-party terms and services;
consult their current official documentation. This project cannot grant model
access or legal clearance.

Security reports must use the private advisory route in `SECURITY.md`, not a
public support issue.
